Trilha 02 - HTML e CSS – Bloq de postagem

Objetivo
Este é o projeto de certificação 2 da Trilha 02 - HTML e CSS. O objetivo é criar uma página web que contenha um input para titulo e outro para escrever um conteúdo. Vamos simular a criação de um post semelhante ao facebook, linkedIn... Onde daremos um título, e escreveremos um texto qualquer e postamos. E o mais legal deste projeto, é que estaremos fazendo uma comunicação com uma API aberta. Simulando um pouco do mundo real.

💻 Tecnologias utilizadas
Esse projeto foi desenvolvido utilizando as seguintes tecnologias:

HTML;
CSS;
Lógica de Programação;

Git e Github;
